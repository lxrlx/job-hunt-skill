# job-hunt-advisor · 通用求职面试助手（WorkBuddy Skill）

一个可直接安装到 [WorkBuddy](https://www.workbuddy.cn) 的**通用**求职面试技能。覆盖从简历到拿 offer 的全流程：简历优化、JD 解读与匹配、BOSS 直聘打招呼语、模拟面试、反问准备、求职计划推进。

> 本技能**不含任何个人隐私**，是一个可复用的方法论框架。首次使用前，把 `job-hunt-advisor/references/profile.md` 里的 `{{占位符}}` 换成你自己的真实信息即可。

## ✨ 功能一览
- **简历优化 / 生成 Word 简历**：按 JD 对标重写，技能分级如实标注，量化值标「参考值」。
- **JD 解读与匹配评估**：三档评估（硬匹配 / 软匹配 / 硬差距），输出匹配度百分比与可视对比。
- **BOSS 直聘打招呼语**：3 个版本（简洁高效 / 真诚务实 / 数据驱动），每版 ≤200 字。
- **模拟面试**：基于你的简历 + JD 生成 5 维度 10 题，按 STAR 结构给反馈。
- **反问 HR 准备**：5 方向各 2 题，避免面试结尾冷场。
- **求职计划推进**：按你填写的约束与分阶段路线跟踪动作。

## 📦 安装方式

### 方式一：从本仓库克隆（推荐）
```bash
git clone https://github.com/lxrlx/job-hunt-skill.git
```
把仓库里的 `job-hunt-advisor/` 文件夹复制到你的 WorkBuddy **用户技能目录**：
- Windows：`%USERPROFILE%\.workbuddy-ai\skills\`
- macOS / Linux：`~/.workbuddy-ai/skills/`

复制后目录应形如：
```
skills/
└── job-hunt-advisor/
    ├── SKILL.md
    └── references/
        └── profile.md
```
重启 / 刷新 WorkBuddy 后，在对话中提到「简历 / JD / 面试 / 模拟面试 / BOSS 打招呼 / 求职计划 / 匹配度 / 反问」等词即可触发。

### 方式二：WorkBuddy 技能市场
若已上架，可在 WorkBuddy 内搜索「求职面试助手」一键安装（无需手动复制文件夹）。

## 🚀 首次使用必做
技能首次运行会读取 `job-hunt-advisor/references/profile.md`。**请先把其中的 `{{占位符}}` 改成你自己的真实信息**（姓名、城市、目标城市、核心经历、技能分级、硬约束），生成的简历、打招呼语、模拟面试才会贴合你的情况。不填占位符，技能会先提示你补全。

## 📐 设计原则
1. **诚实优先**：绝不替你写「精通」；作品集数字不得写成你的个人业绩。
2. **对标 JD**：每条经历 / 技能都映射到目标岗位的具体职责。
3. **量化但标参考值**：估算数字一律标注「参考值」并提醒核实，不编造业绩。
4. **现金流铁律**：若你有「不能断工资」的约束，任何建议都不会让你裸辞。
